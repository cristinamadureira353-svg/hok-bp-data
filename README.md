# 王者荣耀五路 BP 助手：公开基础资料

本发布包含 133 个英雄的编号、名称、推荐分路、职业标签，以及本项目独立整理的基础战术标签。

来源为 [腾讯官网公开英雄列表](https://pvp.qq.com/web201605/js/herolist.json)，读取日期为 2026-10-31。资料不包含皮肤图片、客户个人英雄池或客户游戏画面。

这是机制基础资料包，尚未完成客户真机与实战推荐质量验收。英雄强度字段为 0.5 中性值，没有胜率或禁用率；包含 12 条定性应对、14 条配合机制关系。关系权重 0.55 是人工规则参数，不是统计概率，描述和来源保存在数据中。请勿将此包描述为当前版本强度榜。

发布附件：

- `bp-data.json`：应用读取的数据文件。
- `manifest.json`：格式版本、资料版本、文件大小和 SHA-256。
- `SHA256SUMS`：独立文件校验清单。

资料更新由维护者核对后发布。客户端在局外下载并验证，下一次开始辅助时启用。
