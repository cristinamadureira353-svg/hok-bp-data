# 王者荣耀五路 BP 助手公开资料

`2026.11.05.1` 包含 133 名国服英雄。77 名英雄有定性技能机制标注，资料包含 37 条应对和 39 条配合。相比 `2026.10.31.1` 增加 39 名英雄的机制标注、25 条应对和 25 条配合。

英雄目录于 2026-11-05 复核。机制关系按公开技能独立整理，每条记录附技能来源和使用条件。例如，盘古命中缴械后可压缩后羿的普攻窗口，鲁班大师的链路需要伽罗主动交互才能位移。 [腾讯官网英雄目录](https://pvp.qq.com/web201605/js/herolist.json) · [盘古](https://pvp.qq.com/web201605/herodetail/529.shtml) · [鲁班大师](https://pvp.qq.com/web201605/herodetail/525.shtml)

英雄基础权重统一为 0.5，配对权重统一为 0.55。竞技强度待实战复核。公开附件由英雄目录、项目标注和校验清单组成。

- `bp-data.json` 为 App 读取的资料。
- `manifest.json` 记录版本、文件大小和 SHA-256。
- `SHA256SUMS` 可用于单独校验资料包。

App 在「资料库 → 检查更新」下载并校验资料，下一局启用已下载版本。
